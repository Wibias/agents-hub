# OpenCode — pointer to agent hub

Canonical identity and policy live in `~/.agents`. Do not duplicate them here.

- Voice / worldview: `~/.agents/SOUL.md`
- Full rules: `~/.agents/AGENTS.md`
- Vocabulary: `~/.agents/CONTEXT.md`

Skills live under `~/.agents/skills/`. Prefer discovering that tree over maintaining
a parallel skill farm under OpenCode’s own config directory.

Install this file as the global OpenCode instructions pointer your setup expects
(commonly `~/.config/opencode/AGENTS.md` or the path your OpenCode build documents).
Adjust the destination to match your OpenCode version; keep this file thin.
