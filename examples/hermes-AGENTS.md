# Hermes — pointer to agent hub

Canonical identity and policy live in `~/.agents`. Do not duplicate them here.

- Voice / worldview: `~/.agents/SOUL.md`
- Full rules: `~/.agents/AGENTS.md`
- Vocabulary: `~/.agents/CONTEXT.md`

Skills live under `~/.agents/skills/`.

Place this file where Hermes loads global agent instructions (often
`~/.hermes/AGENTS.md`). If Hermes is not installed, skip this harness.
